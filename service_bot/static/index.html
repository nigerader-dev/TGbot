НАСТОЯЩИЙ TELEGRAM BOT API

Подключите бота к Telegram

Веб-демо уже работает. Для реального Telegram нужен токен вашего бота.

Проверяем статус…

Открыть бота
01

Создайте бота

Откройте @BotFather, выполните /newbot и получите токен.

02

Задайте токен локально

Скопируйте .env.example в .env и заполните TELEGRAM_BOT_TOKEN. Файл исключён из Git. Не присылайте токен в чат.

03

Перезапустите процесс

Из корня репозитория выполните python -m service_bot serve в активированном виртуальном окружении. Запустятся веб-демо и Telegram polling. Для запуска только бота: python -m service_bot telegram. Не запускайте два polling-процесса с одним токеном.

04

Проверьте живой диалог

Откройте своего бота, отправьте /start и четыре тестовых вопроса. Для сброса выбранной модели используйте /reset.

Телефон и адрес сервисного отдела не предоставлены. Помощник не выдумывает контакты.
