## Telegram: что проверено и что не проверено

**Проверено с HTTPX MockTransport:** getMe, getWebhookInfo, setMyCommands, getUpdates,
sendMessage, answerCallbackQuery, текстовые вопросы и кнопки, команды, корректные
offset, отмена polling, повтор отправки без изменения ответа, временные ошибки,
HTTP 429/401/403/409/500, защита токена в сообщениях ошибок, личные чаты и отказ
от удаления существующего webhook.

**Живая проверка в Telegram пока не подтверждена.** Токен предоставлен владельцем,
но в Git не записывается. Текущее подключение Arena получило HTTP 403 при попытке
создать GitHub Actions secret: требуется настройка секрета владельцем репозитория
или переподключение GitHub с нужными разрешениями. Дополнительно запрос к `https://api.telegram.org/` из этого окружения без токена
завершился `httpx.ConnectError`. Это не проверка авторизации и не подтверждение
работы реального бота. Нужны токен и среда с доступом к Telegram API.

После настройки откройте созданного бота, отправьте `/start` и четыре основных
вопроса. Веб-статус покажет проверенное имя бота только после успешного подключения;
при отсутствии подключения он не показывает фиктивную ссылку на Telegram-бота.

Docker-сборка не выполнялась. Результаты удалённых GitHub Actions будут отмечены
отдельно после публикации и фактического выполнения; наличие workflow само по себе
не подтверждает подключение Telegram.
